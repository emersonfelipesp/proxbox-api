# proxbox-api 0.0.28rc1

This is the release candidate for proxbox-api 0.0.28. It carries the complete
0.0.28 change set; only the version differs. See
[proxbox-api 0.0.28](version-0.0.28.md) for the full notes.

Validate this candidate by installing it from TestPyPI in a clean environment,
confirming the health endpoint, and running one node synchronization and one
virtual-machine synchronization before the final 0.0.28 release is promoted.
