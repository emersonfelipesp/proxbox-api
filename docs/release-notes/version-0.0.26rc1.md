# proxbox-api 0.0.26rc1

This is the release candidate for proxbox-api 0.0.26. It carries the complete
0.0.26 change set; only the version differs. See
[proxbox-api 0.0.26](version-0.0.26.md) for the full notes.

Validate this candidate by installing it from TestPyPI in a clean environment,
confirming the health endpoint, and running one node synchronization and one
virtual-machine synchronization before the final 0.0.26 release is promoted.
